# 제출 전 실제 화면으로 교체

아래 파일은 반드시 실제 에뮬레이터와 Supabase 콘솔에서 직접 캡처해 이 폴더에 넣습니다.

1. `01_device_a_write.png` — 기기 A에서 게시글 작성 후 피드에 표시된 화면
2. `02_device_b_sync.png` — 기기 B에서 당겨서 새로고침 후 같은 글이 표시된 화면
3. `03_supabase_posts.png` — Supabase Table Editor의 `posts` 데이터 화면

기존 MP1 참고 이미지는 `mp1_reference/` 폴더에 보관합니다. 평가 증빙에는 위 3장을 사용합니다.
