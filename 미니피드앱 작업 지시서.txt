필수

필수

screenshots/
필수
피드·글쓰기·상세 화면 각 1장 이상. 파일명은 화면 순서대로 01_, 02_ 번호를 붙인 PNG/JPG로 제출합니다. 스크린샷은 최대 12장까지 제출합니다(넘으면 다시 골라 제출해야 합니다). 한 장은 2MB 이하의 PNG/JPG로 제출합니다(2MB를 넘는 이미지는 자동 평가에서 빠지고 강사가 확인합니다).

①  피드·글쓰기·상세 화면 이동
② 새 글 최상단 추가와 상대 시간 표시를 별도 기준으로
③ 더미 데이터에 실제 개인정보 없음
④ README에 화면 구성·더미 데이터 구조·확인 방법·실행 절차 절(더미 데이터 구조 절에는 필드 설명과 데이터 파일 위치)
⑤ 더미 데이터·스크린샷에 실명·연락처·실제 인물 사진 없음 + 민감정보 없음

MP2 서버 동기화 (3개 → 5개)	
① 기기 A 작성 글이 기기 B 새로고침 후 표시
② 익명 인증만, 개인정보 수집 코드 없음
③ 작성 실패 시 크래시 없이 안내
④ 설정 키 하드코딩 금지, .env.example만 제출
⑤ README에 BaaS 선택·익명 인증·백엔드 설정·확인 방법·실행 절차 절

MP3 상호작용과 안전장치 (3개 → 6개)		
① 좋아요 토글 중복 방지 + 동기화
② 댓글 작성·목록을 별도 기준으로
③ 신고 사유 서버 기록(유지)
④ GUIDELINES.md + 민감정보 없음
⑤ 입력 데이터·스크린샷에 실제 개인정보 없음
