# 스크린샷 안내

`README.md`의 "확인 방법"에서 참조하는 파일입니다. Android 에뮬레이터 2대(`Pixel_9`, 기기 A = 5554 / 기기 B = 5556)에서 직접 캡처했습니다. 개별 기기 캡처와, 두 기기를 한 장에 나란히 둔 동시 캡처를 함께 제출합니다.

## MP3 기준 (9장)

### 좋아요
1. `01_like_device_a.png` — 기기 A에서 하트를 눌러 좋아요가 채워지고 숫자가 늘어난 화면
2. `02_like_device_b.png` — 기기 B에서 새로고침 후 같은 글에 좋아요 수가 반영된 화면
3. `03_like_sync_a_b.png` — 기기 A(왼쪽)와 B(오른쪽)를 한 장에 나란히 둔 화면. 같은 글의 좋아요 수가 같고, 내가 누른 하트만 A에서 채워짐

### 댓글
4. `04_comment_device_a.png` — 기기 A에서 댓글을 작성해 목록에 추가된 화면
5. `05_comment_device_b.png` — 기기 B에서 같은 댓글이 보이는 화면
6. `06_comment_sync_a_b.png` — 기기 A(왼쪽)와 B(오른쪽)의 상세 화면을 나란히 둔 화면. 같은 댓글이 양쪽에 표시됨

### 신고
7. `07_report_reason.png` — 신고 모달에서 사유를 선택한 화면
8. `08_report_done.png` — 신고 후 "신고가 접수되었습니다" 안내 화면
9. `09_report_server.png` — Supabase `post_reports` 테이블에 신고가 기록된 화면
