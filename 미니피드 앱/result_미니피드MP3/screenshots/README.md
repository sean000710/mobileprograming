# 스크린샷 안내

`README.md`의 "확인 방법"에서 참조하는 파일입니다. 에뮬레이터 2대(`Medium_Phone_API_36.1`)에서 직접 캡처했습니다.

## MP3 기준 (7장)

1. `01_like_device_a.png` — 기기 A에서 하트를 눌러 좋아요가 채워지고 숫자가 늘어난 화면
2. `02_like_device_b.png` — 기기 B에서 새로고침 후 같은 글에 좋아요 수가 반영된 화면
3. `03_comment_device_a.png` — 기기 A에서 댓글을 작성해 목록에 추가된 화면
4. `04_comment_device_b.png` — 기기 B에서 같은 댓글이 보이는 화면
5. `05_report_reason.png` — 신고 모달에서 사유를 선택한 화면
6. `06_report_done.png` — 신고 후 "신고가 접수되었습니다" 안내 화면
7. `07_report_server.png` — Supabase `post_reports` 테이블에 신고가 기록된 화면

## 기존 파일 (MP2 시절 캡처)

아래 3장은 MP2 단계에서 캡처한 파일이라 위 목록의 파일명과 다릅니다. MP3 확인용으로는 쓰지 않고, 참고용으로만 남겨 둡니다.

- `01_device_a_write.png` — 기기 A에서 글 작성 후 피드에 표시된 화면
- `02_device_b_sync.png` — 기기 B에서 당겨서 새로고침 후 같은 글이 표시된 화면
- `03_write_fail_offline.png` — 네트워크를 끈 상태에서 작성 실패 안내가 표시된 화면
