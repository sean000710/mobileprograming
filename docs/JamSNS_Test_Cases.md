# 잼타(JamSNS) 테스트 케이스 정리

출처: `JamSNS.pen` (15개 화면). 화면 흐름과 UI 문구에서 도출한 기능 검증용 테스트 케이스이며, 디자인에 명시되지 않은 부분은 **[가정]** 으로 표시했다.

우선순위: P0 = 핵심/차단 이슈, P1 = 주요 기능, P2 = 보조/UX

## 1. 화면 ↔ 기능 매핑

| # | 화면 | 핵심 동작 |
|---|------|-----------|
| 1 | 로그인 | 전화번호/비밀번호 로그인, 로그인 상태 유지, 비밀번호 찾기, 회원가입 이동 |
| 2 | 회원가입 | 전화번호, 비밀번호, 학교 이름 입력 + 학교 찾기 |
| 3 | 게시판 선택 | 우리 학교 / 지역 학교 / 학부모 게시판 선택 |
| 4 | 게시판 선택 (학부모 차단) | 학부모 인증 없는 계정의 접근 차단 모달 |
| 5 | 홈 피드 | 공지 바, 인기 게시물, 게시물 카드, 하단 탭 |
| 6 | 게시물 상세 (급식) | 본문, 좋아요, 댓글 목록, 댓글 입력 |
| 7 | 글쓰기 | 제목, 내용(0/1000), 사진 첨부(0/5), 게시 |
| 8 | 홈 피드 (작성 횟수 초과) | 단시간 다중 작성 제한 모달 |
| 9 | 글쓰기 (부적절 내용) | 비속어/개인정보 필터링 모달 |
| 10 | 홈 피드 (신고 모달) / (신고 사유 옵션) | 신고 사유 선택 후 신고 |
| 11 | 쪽지 (받은 / 보낸) | 세그먼트 전환, 미읽음 표시 |
| 12 | 채팅방 | 1:1 메시지 송수신 |
| 13 | 마이페이지 | 닉네임 변경, 익명 표시 토글, 내 활동 |

## 2. 테스트 케이스

### 2.1 인증 – 로그인 (AUTH-LOGIN)

| ID | 우선순위 | 시나리오 | 절차 | 기대 결과 |
|----|---------|----------|------|-----------|
| AUTH-LOGIN-01 | P0 | 정상 로그인 | 가입된 전화번호/비밀번호 입력 후 `로그인` | 게시판 선택(또는 홈 피드)으로 이동 |
| AUTH-LOGIN-02 | P0 | 비밀번호 오류 | 올바른 전화번호 + 틀린 비밀번호 | 로그인 실패 메시지, 화면 유지, 비밀번호 필드 초기화 **[가정]** |
| AUTH-LOGIN-03 | P0 | 미가입 번호 | 존재하지 않는 전화번호 | 실패 메시지 (계정 존재 여부 노출하지 않는 문구) |
| AUTH-LOGIN-04 | P1 | 빈 입력 | 전화번호 또는 비밀번호 공란 후 `로그인` | 요청 미전송, 필수 입력 안내 |
| AUTH-LOGIN-05 | P1 | 전화번호 형식 | 문자/자릿수 부족/하이픈 포함 입력 | 형식 검증 메시지 또는 자동 정규화 |
| AUTH-LOGIN-06 | P1 | 로그인 상태 유지 ON | 체크 후 로그인 → 앱 종료 → 재실행 | 로그인 없이 홈 진입 |
| AUTH-LOGIN-07 | P1 | 로그인 상태 유지 OFF | 체크 해제 후 로그인 → 앱 종료 → 재실행 | 로그인 화면 표시 |
| AUTH-LOGIN-08 | P1 | 비밀번호 찾기 | `비밀번호 찾기` 탭 | 비밀번호 재설정 흐름 진입 **[가정: 디자인 없음]** |
| AUTH-LOGIN-09 | P1 | 회원가입 이동 | `회원가입` 탭 | 회원가입 화면 이동 |
| AUTH-LOGIN-10 | P1 | 비밀번호 마스킹 | 비밀번호 입력 | 입력값 마스킹 |
| AUTH-LOGIN-11 | P2 | 반복 실패 제한 | 연속 N회 실패 | 일시 잠금 또는 지연 **[가정]** |
| AUTH-LOGIN-12 | P2 | 네트워크 오류 | 오프라인에서 로그인 | 오류 안내, 재시도 가능, 크래시 없음 |

### 2.2 인증 – 회원가입 (AUTH-SIGNUP)

| ID | 우선순위 | 시나리오 | 절차 | 기대 결과 |
|----|---------|----------|------|-----------|
| AUTH-SIGNUP-01 | P0 | 정상 가입 | 전화번호, 비밀번호, 학교 선택 후 `회원가입` | 계정 생성, 로그인 또는 로그인 화면 이동 |
| AUTH-SIGNUP-02 | P0 | 중복 전화번호 | 이미 가입된 번호로 가입 | 중복 안내, 계정 미생성 |
| AUTH-SIGNUP-03 | P1 | 필수값 누락 | 각 필드(전화번호/비밀번호/학교)를 하나씩 비움 | 해당 필드 오류 표시, 요청 미전송 |
| AUTH-SIGNUP-04 | P1 | 비밀번호 정책 | 최소 길이/조합 미달 입력 | 정책 안내 **[가정: 정책 미정]** |
| AUTH-SIGNUP-05 | P1 | 학교 찾기 – 검색 | `찾기` 탭 후 "잼타" 검색 | 학교 목록 표시, 선택 시 학교 이름 필드 채워짐 |
| AUTH-SIGNUP-06 | P1 | 학교 찾기 – 결과 없음 | 존재하지 않는 학교명 검색 | 빈 결과 안내 |
| AUTH-SIGNUP-07 | P1 | 학교 직접 입력 | 목록 선택 없이 이름만 직접 입력 | 허용 여부 정책대로 동작(안내 문구상 정확한 학교 선택 권장) |
| AUTH-SIGNUP-08 | P1 | 로그인 이동 | `로그인` 링크 탭 | 로그인 화면 이동 |
| AUTH-SIGNUP-09 | P2 | 전화번호 인증 | 가입 중 인증번호 단계 존재 시 | 인증 성공/실패/만료 처리 **[가정: 디자인 없음]** |
| AUTH-SIGNUP-10 | P2 | 입력 보존 | 학교 찾기 후 복귀 | 이미 입력한 전화번호/비밀번호 유지 |

### 2.3 게시판 선택 및 접근 제어 (BOARD)

| ID | 우선순위 | 시나리오 | 절차 | 기대 결과 |
|----|---------|----------|------|-----------|
| BOARD-01 | P0 | 우리 학교 게시판 | `우리 학교 게시판 보러가기` | 홈 피드에 "우리 학교 게시판 / 소속 학교명" 표시 |
| BOARD-02 | P0 | 지역 학교 게시판 | `지역 학교 게시판 보러가기` | 지역 게시판 피드 표시 |
| BOARD-03 | P0 | 학부모 게시판 – 인증 계정 | 학부모 인증 계정으로 진입 | 학부모 게시판 표시 |
| BOARD-04 | P0 | 학부모 게시판 – 미인증 계정 | 학생 계정으로 진입 | "접근할 수 없어요" 모달, 게시판 내용 미노출 |
| BOARD-05 | P0 | 서버측 권한 검증 | 미인증 계정이 학부모 게시판 API 직접 호출 | 403 등 거부 (클라이언트 모달 우회 불가) |
| BOARD-06 | P1 | 모달 닫기 | 차단 모달에서 `확인했어요` | 모달 닫힘, 게시판 선택 화면 유지 |
| BOARD-07 | P1 | 게시판 전환 | 홈 피드 `게시판 고르러가기` | 게시판 선택 화면 이동, 재선택 시 피드 갱신 |
| BOARD-08 | P1 | 타교 데이터 격리 | 우리 학교 게시판 조회 | 다른 학교 게시물이 섞이지 않음 |
| BOARD-09 | P2 | 선택 기억 | 게시판 선택 후 재실행 | 마지막 선택 게시판 복원 **[가정]** |

### 2.4 홈 피드 (FEED)

| ID | 우선순위 | 시나리오 | 절차 | 기대 결과 |
|----|---------|----------|------|-----------|
| FEED-01 | P0 | 피드 로딩 | 홈 진입 | 상단바(게시판명/학교명), 공지 바, 인기 게시물, 게시물 카드 표시 |
| FEED-02 | P1 | 게시물 카드 표시 | 카드 확인 | 제목, 한 줄 미리보기, 좋아요 수, 학교/작성자/시간 표시 |
| FEED-03 | P1 | 긴 텍스트 처리 | 긴 제목/내용 게시물 | 말줄임(…) 처리, 레이아웃 깨짐 없음 |
| FEED-04 | P1 | 카드 → 상세 | 카드 탭 | 게시물 상세 이동 |
| FEED-05 | P1 | 공지 바 | 공지 바 탭 | 공지 상세 또는 목록 이동 **[가정]** |
| FEED-06 | P1 | 인기 게시물 | 인기 섹션 확인 | 정렬 기준(좋아요 등)에 맞는 게시물 노출 |
| FEED-07 | P1 | 상대 시간 | "5분 전", "32분 전" 등 | 서버 시각 기준 올바른 상대 시간, 경계값(1분 미만/1시간/1일) 정확 |
| FEED-08 | P1 | 빈 피드 | 게시물 없는 게시판 | 빈 상태 안내 |
| FEED-09 | P1 | 새로고침/페이징 | 당겨서 새로고침, 하단 스크롤 | 최신 갱신, 추가 로딩, 중복 없음 |
| FEED-10 | P1 | 하단 탭 이동 | 홈/캘린더/메시지/프로필 탭 | 각 화면 이동, 활성 탭 강조, 홈 복귀 시 상태 유지 |
| FEED-11 | P2 | 익명 작성자 표시 | 익명 게시물 | 작성자 "익명" 표기, 실명/닉네임 비노출 |

### 2.5 게시물 상세 및 댓글 (POST)

| ID | 우선순위 | 시나리오 | 절차 | 기대 결과 |
|----|---------|----------|------|-----------|
| POST-01 | P0 | 상세 표시 | 상세 진입 | 제목, 학교, 작성자, 시간, 좋아요 수, 본문, 댓글 수 표시 |
| POST-02 | P1 | 댓글 수 일치 | "댓글 3개"와 목록 | 표시 수 = 실제 댓글 수 |
| POST-03 | P0 | 댓글 작성 | 입력 후 전송 | 목록 맨 끝(또는 정책 위치)에 추가, 댓글 수 +1, 입력창 비워짐 |
| POST-04 | P1 | 빈 댓글 | 공백만 전송 | 전송 불가 |
| POST-05 | P1 | 댓글 부적절 내용 | 비속어/개인정보 포함 댓글 | 게시글과 동일한 필터 적용 **[가정]** |
| POST-06 | P1 | 좋아요 토글 | 좋아요 탭 → 다시 탭 | +1 후 취소 시 -1, 계정당 1회 |
| POST-07 | P1 | 댓글 좋아요 | 댓글의 숫자(5, 2, 0) 영역 탭 | 개별 토글, 0 표시 정상 |
| POST-08 | P1 | 좋아요 동시성 | 두 계정이 동시에 좋아요 | 카운트 정확 |
| POST-09 | P1 | 뒤로가기 | 상세 → 뒤로 | 피드 스크롤 위치 유지, 변경된 좋아요/댓글 수 반영 |
| POST-10 | P1 | 삭제된 게시물 | 상세 진입 중 삭제됨 | 안내 후 목록 복귀, 크래시 없음 |
| POST-11 | P1 | 상세에서 신고 | 게시물/댓글 신고 진입 | 신고 모달 표시 (2.7 참고) |
| POST-12 | P2 | 긴 본문/이모지 | 이모지 포함 긴 본문 | 줄바꿈·표시 정상 |
| POST-13 | P2 | 키보드 대응 | 댓글 입력창 포커스 | 입력 바가 키보드 위에 위치 |

|----|---------|----------|------|-----------|

| WRITE-06 | P1 | 사진 첨부 | `사진 첨부`로 1장 추가 | 미리보기 표시, 카운터 `1 / 5` |

| WRITE-09 | P1 | 이미지 형식/용량 | 비지원 형식, 대용량 | 거부 안내 **[가정: 제한값 미정]** |
| WRITE-10 | P1 | 갤러리 권한 | 권한 거부 후 사진 첨부 | 안내 및 설정 이동, 크래시 없음 |
| WRITE-11 | P1 | 이중 제출 방지 | `게시` 연타 | 게시물 1건만 생성 |
| WRITE-12 | P2 | 작성 취소 | 입력 중 뒤로가기 | 작성 내용 폐기 확인 **[가정]** |
| WRITE-13 | P2 | 이모지/개행 | 이모지·줄바꿈 포함 | 그대로 저장·표시 |

### 2.7 콘텐츠 제한 및 필터 (GUARD)

### 2.8 신고 (REPORT)

## 3. 디자인 미정/확인 필요 항목

1. 작성 횟수 제한의 구체값(횟수/시간 창).
2. 비밀번호 정책, 닉네임 규칙, 사진 형식·용량 제한.
3. 비밀번호 찾기, 전화번호 인증, 학부모 인증 절차(디자인 화면 없음).
4. 익명 토글의 기존 게시물 소급 여부.
5. 게시물/댓글 수정·삭제, 로그아웃, 계정 탈퇴, 캘린더 탭(디자인에 상세 화면 없음).
6. 신고 `기타` 사유의 추가 입력 여부와 누적 신고 처리 방식.

## 4. 우선 자동화 권장 (P0)

- 단위: 글자 수/사진 수 경계, 필터 판정, 작성 횟수 제한, 상대 시간 포맷.
- 통합/API: 학부모 게시판 권한(BOARD-05), 작성 제한·필터 서버 검증(GUARD-05, 13), 익명 응답(MY-08).
- UI: 로그인 → 게시판 선택 → 글쓰기 → 상세 → 댓글의 핵심 플로우.
